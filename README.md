# Phantom Companions

Aplicación Android de compañeros fantasmales flotantes para el dispositivo K2001N.

## Personajes previstos
- **Fantasma**: criatura blanca con gafas negras, sonrisa confiada y movimientos suaves.
- **Esqueleto**: calavera con capucha oscura, estética gótica y humor misterioso.

Las imágenes de referencia definen la dirección artística; deben incorporarse recursos animados reales con transparencia para producción.

## Proyecto
- Repositorio técnico actual: `cloudemax18/android-k2001n`
- Rama de desarrollo actual: `gengar-floating-companion` (nombre histórico, pendiente de renombrar)
- Prompt de implementación para Gemini: [docs/PROMPT_GEMINI_PHANTOM_COMPANIONS.md](docs/PROMPT_GEMINI_PHANTOM_COMPANIONS.md)

## Funciones objetivo
- Avatar flotante con movimiento aleatorio suave.
- Interacción por toque y arrastre.
- Rutinas horarias y diálogos en español.
- Texto a voz opcional.
- Reacciones opcionales a sensores y ubicación con permisos concedidos.
- Compilación de APK debug mediante Gradle/GitHub Actions.
